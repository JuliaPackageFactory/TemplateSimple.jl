Simple.jl

PkgFactory simple template integration test

Quick Start

Run the following command in the Julia REPL or a notebook:

import Pkg; Pkg.add(url="https://github.com/ohno/Simple.jl.git")

After installation, run the following to load the package and verify it works:

julia> import Simple; Simple.hello()"Hello, World!"
